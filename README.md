# 🚀 mabbdev-scraping-latam

## 🛠️ Requisitos Generales

Cada subproyecto tiene su propio archivo `README.md` o `requirements.txt`/`package.json` con sus dependencias específicas. Sin embargo, a nivel general solemos utilizar:

- **Python 3.10+** (Requests, BeautifulSoup, Playwright, Scrapy)
- **Node.js LTS** (Puppeteer, Axios, Cheerio)
- **Herramientas de automatización de navegadores** configuradas en modo *headless*.
