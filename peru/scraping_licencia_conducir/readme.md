
# 🇵🇪 Consulta Licencia conducir - Script Scraper

Este proyecto es un script en python que automatiza la consulta y extracción de datos de Licencia de conducir en Perú, basada en los tutoriales prácticos del canal **[Mabb.Dev](https://www.youtube.com/@mabbdev)**.

---

## 🛠️ Requisitos e Instalación

Para ejecutar este scraper de forma local en tu entorno de desarrollo, sigue estos pasos:

### 1. Preparar el Entorno Virtual
Crea y activa un entorno virtual de Python dentro de esta carpeta para evitar conflictos de librerías:
```bash
python -m venv venv
```
* **En Windows:**
  ```bash
  .\venv\Scripts\activate
  ```
* **En Linux/Mac:**
  ```bash
  source venv/bin/activate
  ```

### 2. Instalar Dependencias
Asegúrate de instalar los paquetes necesarios que usa el proyecto (Django, requests, noDriver, etc.):
```bash
pip install -r requirements.txt
```


### 3. Ejecutar el script
En la terminal ejecuta:
```bash
python consultalicencia.py
```
