




# 🇵🇪 Consulta CUIT- Script Scraper

Este proyecto es un script en python que automatiza la consulta de DNI , basada en los tutoriales prácticos del canal **[Mabb.Dev](https://www.youtube.com/@mabbdev)**.

---

## 🛠️ Requisitos e Instalación

Para ejecutar este scraper de forma local en tu entorno de desarrollo, sigue estos pasos:

### 1. Preparar el Entorno Virtual
Crea y activa un entorno virtual de Python dentro de esta carpeta para evitar conflictos de librerías:
```bash
python -m venv venv
```
* **En Windows:**
  ```bash
  .\venv\Scripts\activate
  ```
* **En Linux/Mac:**
  ```bash
  source venv/bin/activate
  ```


### 2. Ejecutar el script
En la terminal ejecuta:
```bash
python consulta_cuit.py
```
